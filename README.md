archspin
========

English
-------
VERSION 1.0, THIS IS ONLY A PREVIEW/DEMO

archspin is a lightweight terminal tool that displays the Arch Linux logo with
a visual spinning animation.

It was created for Arch Linux users who enjoy customizing and “ricing” their
desktop and terminal environment. The project focuses on presenting the Arch
Linux identity in a clean, visual, and original way.

The logo is inspired by the Arch Linux logo style used by Fastfetch, but
archspin is an independent project with its own spinning animation. It does not
display RAM, CPU, uptime, kernel, packages, or any other system information.
It only displays the Arch Linux logo.

Features
--------

- Exclusive Arch Linux ASCII logo
- Logo inspired by Fastfetch
- Visual spinning animation
- Designed for Arch Linux ricing
- Horizontal terminal centering
- Configurable colors
- Configurable animation speed
- No external Python dependencies
- Hidden cursor during the animation
- Clean exit with Ctrl+C
- Lightweight and easy to customize
