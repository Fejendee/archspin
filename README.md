archspin
========

English
-------

archspin is a small terminal animation made for Arch Linux users who enjoy
customizing their setup.

It displays an Arch Linux ASCII logo spinning in the terminal. The logo is
inspired by Fastfetch, but archspin is an independent project focused only on
the visual experience. No RAM, CPU, uptime, or other system information—just
the Arch logo spinning for your rice.

You can change the logo color and animation speed directly from the terminal.


Español
-------

archspin es una pequeña animación de terminal creada para usuarios de Arch
Linux a los que les gusta personalizar su setup.

Muestra un logo ASCII de Arch Linux girando en la terminal. El logo está
inspirado en Fastfetch, pero archspin es un proyecto independiente centrado
únicamente en la parte visual. No muestra RAM, CPU, uptime ni información del
sistema: solo el logo de Arch girando para tu rice.

Puedes cambiar el color del logo y la velocidad de la animación directamente
desde la terminal.
